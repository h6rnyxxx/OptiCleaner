# ⚡ OptiCleaner v4.0.0 — Major Architectural & Security Overhaul

**OptiCleaner v4.0.0** — фундаментальный мажорный релиз. Проект полностью переработан из монолитного скрипта в защищенный, компонентный системный комбайн уровня *Process Hacker / BleachBit / CCleaner Pro*.

---

## 🔒 Безопасность и изоляция (Security & AppSec)
- **Тотальная изоляция сервера и бота**: Серверная инфраструктура, база данных лицензий и Telegram-бот полностью вырезаны из публичного репозитория и изолированы в отдельный закрытый репозиторий.
- **Асимметричная криптография Ed25519**: Лицензирование переведено на открытые стандарты с асимметричной цифровой подписью. В клиентском приложении нет симметричных ключей или солей — валидация выполняется строго по публичному ключу.
- **Шифрование настроек DPAPI**: Все пользовательские конфигурации на диске шифруются через Windows Data Protection API (`CryptProtectData`).

---

## 🛠️ Модульная архитектура (Modular Core Engine)
- **Низкоуровневое ядро `core/`**: Разделение абстракций (`base_engine.py`) и платформ (`core/windows/`, `core/linux/`).
- **Транзакционный реестр и точки восстановления**: Перед любым твиком создается официальная контрольная точка восстановления Windows (`RestorePointManager`) и JSON-снимок реестра (`SnapshotEngine`) для гарантированного безопасного отката (`RollbackService`).
- **Сверхнизкая задержка (0.5 мс)**: Поддержка `NtSetTimerResolution` для минимального input lag в соревновательных играх.
- **Game Booster Daemon**: Фоновый процесс автоматического обнаружения 3D-игр с выставлением `HIGH_PRIORITY_CLASS` и оптимизацией ядер.
- **Отказ от WebEngine**: Замена тяжелого 120-мегабайтного движка браузера на нативные аппаратные виджеты `QPainter` (`CyberGauge`).
