# 🤖 Telegram-бот активации и сервер управления лицензиями OptiCleaner Pro

Официальный микросервис автоматической генерации, синхронизации и учёта лицензионных ключей для десктопного приложения **OptiCleaner**.

Включает в себя:
1. **Telegram-бота** (@OptiCleanerActivationBot) на базе aiogram 3.x для моментальной выдачи ключей по HWID.
2. **REST API сервер** на базе FastAPI + Uvicorn для удаленного управления, синхронизации и проверки лицензий.
3. **Модуль базы данных SQLite** с автоматической миграцией, версионированием ключей, архивом удалений (Undo), авто-бэкапами и аудитом действий администратора в `admin_log.txt`.

---

## 📋 Архитектура и принцип работы

```
[Пользователь]
      │
      ▼ (1. Запуск программы)
[OptiCleaner Client] ─── Вычисляет HWID: OC-4BB5-4921-8691-FE80
      │
      ▼ (2. Клик «Отправить HWID в Telegram-бот»)
[Deep Link] ─── https://t.me/OptiCleanerActivationBot?start=OC-4BB5-4921-8691-FE80
      │
      ▼ (3. Открытие Telegram)
[Telegram Bot (@OptiCleanerActivationBot)]
      │
      ├─ Проверяет формат HWID (OC-XXXX-XXXX-XXXX-XXXX)
      ├─ Проверяет статус в базе (active, revoked, unbound, deleted)
      ├─ Генерирует ключ: HMAC-SHA256(HWID + SECRET_SALT + VERSION) -> KEY-XXXX-XXXX-XXXX-XXXX
      ├─ Сохраняет в SQLite (licenses.db): telegram_id, hwid, license_key, tier, status, version
      └─ Отправляет ключ пользователю в чат
      │
      ▼ (4. Копирование ключа в 1 клик)
[OptiCleaner Client] ─── Валидация validate_license_key() -> УСПЕХ!
```

## 👥 Возможности раздела «Управление пользователями» в Админ-панели

В админ-панели OptiCleaner (Master Admin) доступен полнофункциональный раздел **«Управление пользователями & База»**:

1. **Таблица пользователей**:
   - Чекбоксы множественного выбора
   - **HWID** (с моноширинным шрифтом и копированием в клик)
   - **Лицензионный ключ** (с подсветкой синим градиентом)
   - **Telegram ID / @username / Имя**
   - **Тарифный план** (`PRO`, `Universal`, `Maximum`)
   - **Дата выдачи**
   - **Статус** (бейджи: `● Активен` (зеленый), `● Отозван` (красный), `● Развязан` (голубой))
   - **Кнопки действий**:
     - `🔓 Развязать` — отвязывает ключ от HWID для переноса на новый ПК
     - `⛔ Отозвать` — мгновенно блокирует ключ без удаления записи
     - `🗑 Удалить` — удаляет запись, архивирует её и аннулирует ключ

2. **Защита от случайных действий**:
   - **Модальное окно подтверждения**: для массового удаления и очистки базы требует ручного ввода контрольного слова **`DELETE`** или **`УДАЛИТЬ`**.
   - **Автоматический бэкап базы данных**: перед каждым удалением или очисткой автоматически создается файл `backups/licenses_backup_YYYY-MM-DD_HH-MM-SS.db`.
   - **Журнал аудита (`admin_log.txt`)**: фиксирует каждую операцию с датой, временем, HWID, ключом и именем администратора.
   - **Функция «Восстановить (Undo)»**: позволяет вернуть случайно удаленные записи одной кнопкой прямо из интерфейса.

3. **Аннулирование ключей и генерация новых при повторном обращении**:
   - При удалении пользователя запись перемещается в архив `licenses_archive`.
   - Старый ключ аннулируется и при проверке отклоняется как удалённый.
   - При повторном обращении пользователя в бота, счетчик версии ключа автоматически инкрементируется (`version = version + 1`), и пользователю выдается **новый уникальный ключ**, отличный от прежнего!

## 🚀 Запуск компонентов

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск Telegram-бота
```bash
python main.py
```

### 3. Запуск REST API сервера (FastAPI)
Если бот размещен на VPS или отдельном сервере:
```bash
python api_server.py
```
Сервер запустится на `http://0.0.0.0:8000`.
Интерактивная документация Swagger доступна по адресу:
`http://localhost:8000/docs`

## 🌐 Настройка синхронизации в OptiCleaner

В админ-панели OptiCleaner нажмите кнопку **«⚙ Настройки подключения»**:
* **Режим 1 (Локальная база)**: укажите путь к файлу `licenses.db` (по умолчанию определяется автоматически).
* **Режим 2 (REST API сервер)**: укажите адрес API (например `http://127.0.0.1:8000` или `http://your-vps-ip:8000`) и секретный ключ `OptiCleaner-Admin-Secret-Key-2026`. Нажмите «Проверить связь» и «Сохранить».

## 🛠️ Команды Telegram-бота

* `/start` — Инструкция по получению лицензии.
* `/start OC-XXXX-XXXX-XXXX-XXXX` (Deep Link) — Моментальная выдача или перепривязка ключа.
* `/mykey` — Список всех ключей пользователя с отображением тарифа и статуса.
* `/help` — Справка по HWID и переносу ключа.
* `/stats` *(для администраторов)* — Подробная статистика: всего активных, отозванных, отвязанных и архивированных лицензий.
